# Contributing to Empower Retirement Account

## Contribution Guidelines
We welcome contributions! To contribute:
- Fork the repository.
- Create a new branch for your changes.
- Follow the project's coding standards.
- Commit your changes and push to your fork.
- Open a pull request to the main branch.
- Refer to this file for detailed guidelines.

## How to Contribute
- Ensure code is clean, well‑documented, and tested.
- Write meaningful commit messages.
- Keep pull requests focused and concise.

## Reporting Issues
- Use the GitHub Issues tab.
- Provide clear steps to reproduce the problem.
- Include screenshots or logs if relevant.

## Suggesting Features
- Open a feature request in Issues.
- Explain the use case and expected outcome.

## Code of Conduct
- Be respectful and inclusive.
- No harassment or offensive language.
- Collaborate constructively.

## Review Process
- Maintainers review all pull requests.
- Feedback will be shared for improvements.
- Approved changes are merged into the main branch.
